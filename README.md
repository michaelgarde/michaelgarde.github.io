# 🎪 Michael Garde's Digital Playground

Welcome to my completely wacky GitHub Pages site! This isn't your typical developer portfolio - oh no! This is a **digital carnival** where code meets chaos, where logic dances with lunacy, and where every click might lead to something unexpected.

## 🎯 What's This All About?

This site is built with Jekyll and GitHub Pages, but with a twist - it's designed to be fun, interactive, and full of surprises. Think of it as a digital playground where visitors can explore, experiment, and discover hidden secrets.

## 🎪 Local Development

To run this site locally:

1. **Install Jekyll**:
   ```bash
   gem install jekyll bundler
   ```

2. **Clone the repository**:
   ```bash
   git clone https://github.com/michaelgarde/michaelgarde.github.io.git
   cd michaelgarde.github.io
   ```

3. **Run the development server**:
   ```bash
   jekyll serve
   ```

4. **Open your browser** to `http://localhost:4000`
